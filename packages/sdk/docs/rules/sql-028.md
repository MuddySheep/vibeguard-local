# SQL-028 — pg_create_*_replication_slot

  | | |
  |---|---|
  | **Severity** | `warn` |
  | **Confidence** | 80 |
  | **Threat category** | `exfiltration` |
  | **Default** | ON |

  ## Pattern

  Creating a logical or physical replication slot opens a long-lived stream of database changes to whoever connects to the slot. It is also a frequent operational footgun: orphaned slots prevent WAL recycling and eventually fill the disk.

  ## Status

  This catch ID is **reserved** as part of the v1.1 Postgres catalog
  expansion. The forever-stable ID guarantee in
  [STABILITY.md](../../STABILITY.md) applies from the moment this entry
  ships in `RULE_REGISTRY`. Detection logic is being implemented in a
  follow-up v1.1 phase; until then the rule is registered as a no-op
  placeholder so consumers can already key on the ID.
